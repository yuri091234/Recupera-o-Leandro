# Sistema de Cadastro de Medicamentos

## Descrição

Este projeto é um sistema simples de cadastro de medicamentos feito em Python.

O sistema permite cadastrar, listar e buscar medicamentos.

## Como executar

1. Instale o Python.
2. Abra a pasta do projeto.
3. Execute o arquivo `main.py`.

```bash
python main.py
```

## Funcionalidades

* Cadastrar medicamentos
* Listar medicamentos
* Buscar medicamento pelo nome
* Salvar os medicamentos em arquivo
* Carregar os medicamentos quando o programa inicia

## Requisitos técnicos utilizados

* `if/elif/else`: usado no menu principal.
* `while`: mantém o menu funcionando até escolher a opção sair.
* Funções: usadas para carregar, salvar e buscar medicamentos.
* Lista de dicionários: utilizada para armazenar os medicamentos.
* Arquivo CSV: utilizado para salvar os dados.
* Biblioteca padrão: foi utilizada apenas a biblioteca `csv`.
